# Bloged terminology

Use these terms in Bloged documentation, UI text, and code comments.

| Concept | Approved term | Do not use |
| --- | --- | --- |
| Selected blog folder | project | workspace, site folder |
| Named content folder | content package | collection, source |
| Folder that contains a post Markdown file | post | article folder, entry |
| Running local site command | development server | dev server, server process |
| Browser area in the app | preview | web view, browser pane |
| Searchable command interface | command palette | quick switcher, launcher |
| Generator integration choice | preset | template, profile |
